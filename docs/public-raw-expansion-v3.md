# Additional public camera-native sources

**18 new source-reviewed CC0 RAWs are admitted to a separate future dataset.**
The public/native extension has 146 captures in 124 declared groups across 96
camera strings, up from 128/106/78. Attaching the unchanged 22-source personal
admission produces a separate private 168-capture/138-group extension. Neither
is used by the running original 20k V84/V85 comparison. More sources and declared
groups do not establish independent scenes or a trained quality gain.
[Pinned admission](results/public-raw-admission-v3.json) and
[completed source review](results/public-raw-expansion-v3-source-review-v1.json).

The 36-source acquisition downloaded 1,232,464,639 bytes. Independent review
checked all 36 original SHA256/byte counts and archived metadata hashes, 68
native uint16 cache hashes/headers, 68 inspection-cache/preview hashes and 34
actual ISO/clipping calculations. All 49 frozen workflow files stayed unchanged;
all 44 package files matched the actual trainer before the new admission pin.
[Preparation observation](results/public-raw-expansion-v3-prepared-v1.json).

Of 36 acquired files, 34 decode to ordinary Bayer targets. Galaxy S23 Ultra file
7104 is not ordinary 2×2 Bayer; S23+ file 7150 produces a LibRaw data/format error. Both match
the publisher checksum and remain rejected. Seven further sources fail the
existing ≤.001 any-channel near-white fraction at code 65500; these include the
all-magenta/full-clipping Canon R6 III decode 8961. Five color-chart and three
staged dice/cloth/tool sources are excluded. Accepting CR3 as a download suffix
does not establish useful decoding or training support.

The resulting 19 photographic candidates received two complementary screens:

- Genuine frozen DINOv3 ConvNeXt-Tiny features on CPU compare against six fixed
  pools: 427 historical development photos, 85,048 historical Commons training
  sources, 150 native sources, 45 protected cached captures, 1,188 new Commons
  sources and 34 new RAWs. All 342 top-three cosines were independently rebuilt
  with FP64 arithmetic; all 114 first-rank source pairs were actually viewed.
  RAW 1458 depicts the same Gdańsk station site as two historical Commons
  training sources and is withheld. Its nearest development tower is a
  different named Wrocław site. The earlier
  [progress receipt](results/public-raw-expansion-v3-content-progress-v1.json)
  preserves the observation before the pixel flags were resolved.
- Pixel fingerprints compare seven source/center/corner views, both-sided D4
  transforms and aspect/contrast guards against native/protected/new RAWs, plus
  an unchanged read-only fingerprint database covering 95,634 Commons sources.
  All 49 flagged full-source/ROI pairs were actually viewed on five sheets.
  They are smooth sky/gradient or unrelated structural similarities; no
  additional recognizable source identity was established. This pixel screen
  missed the actual Gdańsk site match found by DINO. Finite retrieval, chosen
  thresholds and manual views cannot prove universal scene independence.

All 34 source thumbnails and one full packet-display preview were also viewed.

all 108 sampled uint16 codes on six actual container types at both 4× and 8×.

does not independently validate sensor calibration or make the targets noiseless.
Private reference pixels and per-capture review rows remain outside Git.

## Metadata provenance

The bounded survey reuses the immutable 2,016-entry catalog snapshot from the
earlier public work, not the latest catalog. It checks 62 models absent from
prior-v2 metadata records, with at most two variants/model and eight models/make,
requiring explicit per-entry CC0, ≥12 catalog MPix and metadata ISO ≤200.
Monochrome, reduced/pixel-shift/crop modes and declared unseen camera aliases
are excluded. Requests start at most once/second, with 20s timeouts and a 1MiB
cap. Seventy-nine requests yield 37 low-ISO matches. The acquired-source/current
native identity filter removes one previously downloaded Panasonic file,
leaving 36. Oversized/unsuitable responses stay excluded.
[Original metadata observation and tests](results/public-raw-expansion-v3-metadata-v1.json).

The user's hot local RAW directory contains RAF files only. Public acquisition
adds other-camera examples without accessing source archive drives. The
[publisher](https://raw.pixls.us/) requests low-ISO scenery and provides
per-entry license links. Selection requires each actual CC0 link, published
RAW SHA256 and pinned EXIF payload. Acquisition accepts CR2/CR3, PEF, ORF, SRW
and NRW alongside the earlier formats, retaining the existing host/license/
checksum/protected-capture checks. Container acceptance and metadata selection
remain separate from actual decode, source review and admission.
