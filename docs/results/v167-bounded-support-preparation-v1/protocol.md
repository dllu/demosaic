# Bounded spectral support: V167

V167 tests whether a lower bound on local spectral support can preserve fine dark detail after V166's gate suppression. The fixed training and quality comparison are pending; no improvement is claimed yet.

The candidate uses support `f + (1-f) sigmoid(logit + log(1-2f))`, with `f = 0.25`. The offset preserves support 0.5 at zero logits, matching the control's initializer. Both heads initially return the exact V143 parent. The candidate support stays between 0.25 and 1, while the control uses the original sigmoid. This changes the mapping and its derivative: at zero logits the derivative is 1/6 versus 1/4. The frequency gains can still vanish, and the direct RGB path can cancel a correction. A bounded gate does not guarantee delivered detail or safe noisy flats.

Both heads retain V166's common-loss fixed-support backward routing, common weight 1 with 16 DN16 units, pair-difference weight 1 with a 2 DN16 floor and epsilon .003, flat anchor .25, and all existing losses. Data, initialization, LR, AdamW, clipping, EMA and the fixed 1,000-update horizon match. `routed-control` must reproduce every V166 `routed-common` trace row, final raw/EMA/Adam state and all 1,644 actual predictions before archive storage is adopted.

All 89 prior neural source files remain byte-identical; one new module brings the source count to 90. Its forward preserves the inherited arithmetic order, with one spectral synthesis, one Malvar reconstruction and one direct RGB evaluation. The existing training-only common routing repeats synthesis/Malvar on 691 paired batches per head, including 71 zero-weight ADC batches.
