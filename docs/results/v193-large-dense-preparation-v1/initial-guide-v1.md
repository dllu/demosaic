# Larger dense spectral window (V193)

V193 tests whether a longer coherent measurement window helps recover weak mesh detail. The [V192 analytical calculation](dense-measurement-support.md) found that a Hann65 taper uses much less coherent support than a rectangular65 window; its fixed Hann129 cases recover more support. That calculation does not establish learned quality or flat-field safety. The matched training run is active; V187 remains the preferred experimental wave model and V120 Small the general recommendation.

The neural implementation is exactly the completed [V191 dense readout](dense-local-spectrum-readout.md): all 103 neural source files are unchanged. The large dense window changes from 65 to 129 packed pixels, its stride from 32 to 64, and its carrier grid changes with the window. The nested 33/17 windows, frozen matching65/32, raw coefficient units, native-phase IFFT and Hann overlap synthesis remain the same. Window, grid and stride change together; this does not isolate their individual effects. Larger windows might also spread structure across boundaries.
