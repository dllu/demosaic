original4000 budget. Its model/EMA/AdamW, Python/CPU/CUDA RNG and best state
exactly match the earlier V81 connected checkpoint at1000. All56 sampled input/
legacy-target batches and41 logged training rows match, apart from timing and

The CPU report preparation is now queued behind the exact
[full review](bank-detachment-review-queue.md) owner exit. It audits saved hue
prediction arrays and rendered cells, hue summaries, complete analytic arithmetic
and the predeclared primary/weak-carrier/ADC criteria. It builds the eight native

RawNIND source pixels. Both waiters are live with CUDA hidden and no children;
they perform no current-model inference or scoring while training/review is live.

A complete historical preflight verified the new entrypoint before queueing it:
3528 saved predictions/21,168 metric fields,54 hue groups/648 summary values,
1344 analytic rows/2256 summary values, and all eight closure plus four baseline
board images reproduced pixel-for-pixel. Historical V80/V81 checkpoint labels
and the adverse ADC contrast remain original. No V82/V83 performance is inferred
from that replay, and no additional model training was needed.

The first preflight caught an output-location error before auditing arrays:
the frozen package's path guard requires outputs inside its work directory or
`/mnt/external`. The corrected preflight clones identical historical code into
its own work directory; production outputs stay inside the actual review work
directory. The failed plan/log and corrected receipt are preserved. The guard
was retained, and no live training/review source was changed.

All generated boards still require actual native inspection. That inspection
includes at least two noisy/restored/exact-GT triplets per checkpoint, fixed
coordinates/transforms, checkpoint hashes, noise/display exposure, and cached
GFX sky/building/foliage/chain-link-fence/lights. ISO100 remains an independent
qualitative reference. Board construction never resizes the crop pixels and
never marks visual review complete. V43/default/README pixels remain unchanged;
no automatic continuation, full-frame run or promotion follows preparation.
