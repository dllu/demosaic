This is a new architecture under engineering evaluation; **trained quality is not established**. [The V196 input diagnostic](innovation-frequency-selection.md) finds a weak coarse crossing that the current RAW selector misses. It motivates measuring what the existing output leaves unexplained, while retaining that output as a frozen anchor.

`LateInnovationWaveDetail` preserves every trained V195 Whole EMA tensor and adds a fresh `SpatialContextWaveReadout`: four tensors, 508 trainable parameters, 197 total state tensors. The existing 193 tensors remain frozen. A zero final layer initially preserves the anchor output. RAW and innovation arms start with identical new parameters and fresh Adam/EMA clocks zero; engineering probes are never future training initializers.

Both arms use eight selected bins in the native 1/64…1/3 band, 65px packed evidence windows and 33/17px support windows, with the previous strides and readout. RAW control measures observed packed RAW. Innovation measures RAW minus the frozen anchor's camera RGB sampled at each actual CFA phase. **Selection and the local wave/support measurements change together.** The supplied RAW variance remains a nominal normalization convention for the correlated innovation, not a residual-noise estimate or confidence probability.

Only the new head differentiates through the output. The complete anchor and all measurement extraction run without gradients. The added correction uses the existing local noise RMS and exact zero-variance routing. On ADC-only inputs, the new selector/readout are bypassed. These architectural properties do not guarantee flat safety after training: the head can still add false waves or alter retained structure.
