## Where the time and precision go

V120 took 329.42 and 363.95 seconds to restore 101.996 MP in two archived FP32 runs with different noise conditioning on a shared GB10. They used batches of four 512-pixel tiles, overlap 64, and processed 136.3 MP across 520 tiles. Decode, startup and export add separate costs. DRUNet alone has 56 dense 3×3 convolutions in its residual blocks, an estimated 206 trillion multiply-accumulates per 100 MP before overlap. The split of elapsed time between DINO and DRUNet still needs measurement. The strongest local speed result is hidden FP16 on V43/V63, which cut resident four-tile forward time by about 4×. A subsequent same-policy replay exceeded the study’s one-DN16 maximum discrepancy on three V43 crops. These observations justify a fresh V120 measurement against its own FP32 output. | Part of the model | First precision to try | Reason |
| --- | --- | --- |
| Bayer input, black/white normalization, noise variance, Malvar reconstruction and transforms | FP32 | Dark read variances and subtle color differences need precision before the network sees them. |
| DINOv3 ConvNeXt context | FP16 baseline, then selected NVFP4 linear weights and activations | Each ConvNeXt block has two pointwise linear projections. Test those first. Keep depthwise convolutions, normalization and fusion at baseline precision for this comparison. |
| DRUNet hidden encoder and decoder | FP16, then FP8 on profiled dense convolutions | This is a large share of the model’s arithmetic. Start FP8 in one group of expensive blocks so an error can be traced to the change. |
| Native-resolution skip, final residual addition and RGB head, inverse transforms and tile blending | FP32 through accumulation, then RGB16 export | Around normalized 0.5, the FP16 step upwards is about 32 output codes. A small residual added in FP16 can round away before export. V120 already preserves the first native skip and final addition in FP32. |

The actual GB10 engine determines the payoff. ModelOpt can calibrate existing weights, select layers, simulate quantization error and export a model for deployment. NVIDIA demonstrates NVFP4 on DGX Spark for language models. TensorRT 11.4.1’s convolution operator lists FP16, BF16, FP32, INT8 and FP8. For this architecture the natural first NVFP4 candidates are the encoder’s linear projections. Inspect the built engine and time the selected kernels, including casts and changes of tensor layout. A lower average bit count alone measures storage. ## The first benchmark

1. **Measure V120 FP32 and hidden FP16 on identical inputs.** Start with the existing inference path. Hold tile geometry, batch, noise profile and output transform fixed. Time DINO, the restoration trunk and blending with synchronized GPU timings. Measure cold RAW-to-TIFF latency and repeated warm full-frame latency separately, with peak memory and output checks. Record the checkpoint hash, backend versions and actual layer dtypes. The project’s production target is ten seconds for 100 MP.
2. **Measure the TensorRT FP16 baseline before changing bit depth.** Compile the same neural regions and confirm that the FP32 boundaries survive export. Against this baseline, test DINO-only NVFP4 and trunk-only FP8 separately, then combine the winners. Profile the fallback layers and conversion overhead. For example, if DINO takes 20% of runtime, even a 2× faster DINO saves only 10% of total time. Use the measured fraction to decide whether to explore more layers.
3. **Calibrate on training data and judge on held-out images.** Cover near-zero noise, high ISO, deep shadows, saturated colors, smooth gradients and faint colored lines. Keep the protected GFX families and fixed evaluation photos out of calibration. Start with post-training quantization. If one layer group erases detail, restore its precision and rerun the same cases before considering quantization-aware training.
4. **Measure image fidelity where we know it can fail.** On matched synthetic targets, report weak-wire response in both directions alongside fine-increment error, quiet-region luma/chroma RMS and flat-color bias tails. Include ramps and tile seams. Inspect both GFX fence families at native scale, with sky and building controls and both fine-cab profiles. Use the independent ISO100 captures and JPEGs for visual comparison. For the fastest promising configuration, finish the fixed photo/camera panels and time the full 102 MP export. Report paired differences against the same checkpoint’s FP32 result.

Run the first screen on V120, the general recommendation. Repeat the winning precision policy on Corpus 100k using its **own** FP32 baseline and calibration scales. Its broad photo gain is now large enough to protect, while the clipped yellow dahlia gives a concrete regression to check. If profiling leaves the dense trunk far above the time budget, compare a narrower distilled trunk before spending more effort on the encoder. ## How the implementation work affects this plan

- **Longer training produced a broad gain.** Corpus 100k reached 37.24747 dB on the fixed photo panel, +0.20739 dB over V120 with 423/427 sources improving. Unseen-camera PSNR fell 0.03046 dB. In the weakest ISO12800 band, recovered response stayed near 36.5% even as error fell. Both the paired baseline and the separate response/error measurements matter when choosing faster arithmetic. [Broad results](full-corpus-long100k.md) · [Weak-band measurements](full-corpus-long100k-weak-band.md)
- **Scene context has a measurable flat-region benefit.** On 48 additional photo backgrounds with independent ISO6400 draws, aligned regional context lowered fine flat RMS by 0.118 DN16 versus the coarse full preview and 0.110 versus flipped context. Fine-increment error rose slightly on coupled draws. In the separate 50k training study, both arms had verified identical inputs through 13,500 updates at this review’s cutoff. The 12k quality monitor reuses eight development backgrounds. A fresh held-out check at the next reviewed milestone would distinguish a repeatable gain from a favorable monitor result. [Regional-context comparison](scene-regional-context.md) · [Full-epoch study](scene-full-epoch.md)
- **The green fence has a visible, bounded improvement.** Fitting wire frequencies from disjoint regions of the noisy scene produces a faint left-cab lattice under both profiles. It still looks overly regular in places. The subsequent chroma check raised aligned chroma response from 34.40% to 38.74% on 16 constructed colored fields. It also added color in some true gaps and reproduced the preceding result in all eight standing real crops. These are good tests for quantization damage. The deployment cost of the optional Bayer correction should be measured separately if it ships. [Exterior-fit native boards](query-donor-composition.md) · [Reserved-color test](query-signed-colour.md)
- **Evaluation and production measure different workloads.** A 12-batch probe per checkpoint recorded 377.90 seconds of summed CPU forwards and 36.67 seconds of CUDA FP32 forwards for V120 and Corpus 20k in different sessions. The full-frame measurements linked above include tile transfer and blending, and time export separately.
