# Smaller RAW support for the wave readout (V185)

V184 increased constructed weak-mesh response, but also added false fine striping beside quiet steps, bars and stripe patches. V185 tests whether smaller spatial measurements help its readout distinguish nearby structure from large-window spillover. **Training is in progress; no V185 quality gain is established.** The [completed V184 comparison](phase-wave-readout-comparison.md) remains the latest measured result.

The large 65-packed-pixel wave basis, selected frequencies and frozen V183 EMA baseline are unchanged. Two additional 33- and 17-packed-pixel windows measure those same frequencies on an 8-packed-pixel grid. Each contributes six context channels: two powers, signed complex cross evidence and frequency coordinates weighted by measured strength. These overlapping measurements reuse noisy samples; they are neither independent tests nor calibrated confidence.

The readout grows from 316 to 508 parameters (18→16→12). Its original six hidden input weights and bias are copied exactly at initialization, the twelve extra input weights start at zero, and its final mixing layer starts at zero. All 189 inherited tensors remain frozen and in evaluation mode. A fresh 900-update head run uses V184's same 1,000 cached rows, 3,600 noisy images, 100 ADC skips, nine losses, masks, domain weights, learning-rate schedule and head EMA clock. Primary comparisons will be V185 raw versus V184 raw and V185 EMA versus V184 EMA. Capacity and spatial context change together.

Preparation passed 37 model CPU tests and 19 codec/state checks; about 102 million native support values match independent NumPy calculations across six cached batches. Seven GPU initial outputs reproduce V183 exactly; six nonzero head checks, all 508 CPU/GPU gradient coordinates over two updates, and a genuine model/Adam/EMA/RNG restore pass. Peak admission allocation was 6.24 GiB. Protected GFX sky and cab inputs serve inference checks only; they and their siblings remain excluded from training. [Machine receipts](results/v185-spatial-context-preparation-v1.json) retain failed CPU-harness attempts and their corrections.

Future native outputs use lossless byte-plane compression. An RGB manifest may reference exact FP32 addition of its immutable V183 baseline and stored wave only after checking every output bit; otherwise it stores XOR bytes. Signed zero has explicit coverage. Future checkpoints store the four head tensors, Adam, EMA and RNG plus a checked immutable initializer binding; strict reconstruction retains all 193 tensors. Existing checkpoints, arrays and receipts are unchanged. Consolidating identical completed output arrays and immutable source snapshots preserves every path and hash, without lowering disk reserves.

Both trained endpoints still require the full 822-case review, independent audits and native viewing, including main-scene sky, building, foliage and coarse fence, and the difficult fine cab mesh with independent ISO100/AHD and SOOC JPEG references. Those real references differ in aperture, exposure, processing and motion; they are not exact GT.
