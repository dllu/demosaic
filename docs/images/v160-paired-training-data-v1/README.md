# V160 training-input inspection credits

These sheets show constructed training targets and noisy inputs, without a
restoration model. Cells are native 160×160. Full source, ROI, camera, noise,
exposure and attribution records are in the
[inspection manifest](../../results/v160-paired-response-preparation-v1/input-inspection.json).

- `sheet-00.png`, photographic row: [Castillo San Felipe de Barajas, Cartagena 26](https://commons.wikimedia.org/wiki/File:Castillo_San_Felipe_de_Barajas,_Cartagena_26.jpg), Bernard Gagnon, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `sheet-01.png`, photographic row: [Sir Tony Hoare IMG 5125](https://commons.wikimedia.org/wiki/File:Sir_Tony_Hoare_IMG_5125.jpg), photograph by Rama, Wikimedia Commons, [CC BY-SA 2.0 fr](https://creativecommons.org/licenses/by-sa/2.0/fr/deed.en).

Photographic derivatives retain their respective source licenses. Changes
include cropping, geometric augmentation, area binning, exposure/contrast,
constructed channel-mean backgrounds, simulated Bayer noise and RGB display
conversion. Other rows use the project's procedural textures.
